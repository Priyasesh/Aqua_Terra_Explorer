# Aqua Terra Explorer — Multi-Sensor Environmental Monitoring & Data Fusion System

A browser-based interactive dashboard that simulates a robotic environmental monitoring system integrating camera, sonar, and ground-penetrating radar data.  
Built as a portfolio project to showcase multi-sensor data analysis, cross-sensor validation, anomaly detection, and decision-support workflows using HTML, CSS, and JavaScript.

## What It Does

This project simulates and visualizes a 5-stage environmental monitoring workflow:

| Stage | Name | What Happens |
|---|---|---|
| 1 | Sensor Input Capture | Camera, sonar, and ground-penetrating radar inputs are collected and monitored in parallel |
| 2 | Data Structuring | Raw sensor outputs are transformed into organized values for alignment, comparison, and visualization |
| 3 | Cross-Sensor Validation | Camera, sonar, and subsurface data are compared to detect mismatches and improve consistency |
| 4 | Fusion & Analysis | Processed inputs are fused into a unified monitoring view for anomaly detection and performance review |
| 5 | Decision Support | Accuracy metrics, anomaly trends, and subsurface insights are presented for operational decision-making |

## Key Features

- **Multi-Sensor Dashboard** — Displays camera, sonar, and GPR data streams in a unified monitoring interface.
- **Data Fusion Pipeline** — Visualizes the flow from raw data to cleaned, fused, and validated outputs.
- **Consistency Analysis** — Shows cross-sensor alignment, inconsistencies, and anomaly counts.
- **Subsurface Visualization** — Simulates underground object detection such as metallic debris, pipe structures, and cavities.
- **Live Analysis Mode** — Updates metrics dynamically to simulate real-time environmental monitoring.
- **Performance Metrics** — Highlights operational accuracy, total objects detected, and total data processed.
- **Trend Visualization** — Uses charts to show alignment and anomaly trends over time.
- **Export Report** — Generates a downloadable analysis report.
- **Light & Dark Mode** — Supports theme switching for different viewing preferences.
- **Responsive Design** — Works across desktop, tablet, and mobile layouts.

## How to Run Locally

No installation required. This is a static website — just open the file.

- Download or clone this repository
- Open `index.html` in any modern browser
- Or run it using Live Server in VS Code

```bash
git clone https://github.com/Priyasesh/AQUA_TERRA_EXPLORER.git
cd AQUA_TERRA_EXPLORER
open index.html
```

## Academic / Project Context

This project is based on a final-year robotics and environmental monitoring concept focused on improving environmental detection accuracy through multi-sensor data analysis.

Core project focus:
- Processed and analyzed large-scale multi-sensor datasets
- Improved consistency between sonar, visual, and subsurface sensor inputs
- Identified anomalies and error patterns affecting detection performance
- Structured raw data for downstream processing and decision workflows

Impact achieved: Improved multi-source data consistency, contributing to approximately **95% operational accuracy** and more reliable environmental detection outcomes.
